Repodest for GitHub

Health score & LLM-ready digests, right on the repo page · v1.0.0

GitHub token (optional)

Without a token you get 60 GitHub API calls per hour. A free personal access token raises that to 5,000/hour. The token is stored only in your browser and is sent only to api.github.com.

Create a token → No extra scopes needed for public repos (classic: no scopes / fine-grained: public repositories, read-only).

Cache

Repository data is cached locally for 6 hours (activity for 1 hour) to save API calls. Nothing ever leaves your browser.
